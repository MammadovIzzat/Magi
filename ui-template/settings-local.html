Team server

Working locally

Everything you create stays in this install. Connect to a team server to share engagements — you will need the server address, a one-time code from an admin, a name and a password. The admin then approves your request.

Encryption at rest

The database is stored unencrypted. Set a passphrase to encrypt it with SQLCipher; you then enter it each time Magi starts.
