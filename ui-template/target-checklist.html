01
Directory / file enumeration — unauthenticated

As an anonymous attacker, with no session. This is the baseline of what is exposed to the internet: hidden dirs, admin panels, backups, dev endpoints.

02
Directory / file enumeration — authenticated

Repeat with a valid session — it surfaces user- and admin-only routes, API endpoints and account pages the anonymous run never sees. Carry the session on every request, filter out the login-redirect length, and watch for the fuzzer logging itself out (session fixation / CSRF).
